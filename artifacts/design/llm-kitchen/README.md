# Kitchen evidence

The release candidate is the garden-to-table journey that actually trains an isolated tiny model. Current authoritative checks are `cook-real.json` (one actual WASM optimizer step and same-weight generation/export), `cook-ui.json` (controlled worker, full lifecycle and responsive journey), `export-reopen.json` (real checkpoint reopened/continued in Web Lab), `opening-final-review.json`, and `viewport-review.json`.

The single-step run verifies integration, not full-run model quality. Earlier directions, independent pretrained-chat experiments, and screenshots remain historical development evidence; they are not the current runtime. SFT/preference activities remain labelled illustrations. Deployment/CI receipts are tracked in GitHub Issue #182.
