# Why

PostTrainLLM has extensive factory documentation and public artifacts, but category searchers land on internal documentation rather than a coherent practical curriculum. The site needs a durable bridge from Mac-local fine-tuning questions to the factory, evaluation, packages, and honest report cards.

# What changes

- Add five public guides covering Mac fine-tuning, MLX LoRA, local evaluation, trajectory datasets, and specialist models.
- Add a reusable evidence-first reading layout and content registry.
- Include every guide in sitemap and generated agent surfaces.
- Add contextual links from the homepage, recipes, artifacts, and evaluation pages.

# Out of scope

- Model loading, GPU work, training, new benchmark results, artifact publication, new dependencies, or runtime behavior.

# Impact

Only the Astro browser/readout surface changes. The factory CLI, native app, evals, models, and active unrelated benchmark work remain untouched.
