# Public specialist content

## ADDED Requirements

### Requirement: Mac-local specialist curriculum
The browser site SHALL expose canonical guides for Mac fine-tuning, MLX LoRA, local LLM evaluation, agent trajectory datasets, and small specialist models.

#### Scenario: Reader follows the factory loop
- **WHEN** a reader enters through any guide
- **THEN** the guide answers its primary question, links to adjacent steps, and leads to public artifacts, report cards, recipes, or evals

### Requirement: Evidence state remains explicit
Every material product result SHALL identify its measured scope and disclose regressions, routing constraints, or unavailable measurements.

#### Scenario: A narrow specialist result is cited
- **WHEN** a page cites the file-operations specialist
- **THEN** both the target gain and out-of-domain regression are visible and the model is described as routed

### Requirement: Agent-readable parity
The post-build agent generator SHALL emit substantive Markdown and catalog entries for every new canonical guide from the same content source.

#### Scenario: Agent surfaces are checked
- **WHEN** the existing agent-surface check runs
- **THEN** all five guides appear with canonical URLs and substantive content

### Requirement: Search and accessibility integrity
Every new guide SHALL include canonical metadata, supported structured data, sitemap inclusion, semantic heading order, visible focus, and responsive reading behavior.

#### Scenario: Reader uses a narrow viewport
- **WHEN** the page renders at 390 pixels
- **THEN** prose, code, tables, links, and CTAs remain readable without page-level horizontal scrolling
