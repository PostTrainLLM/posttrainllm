work should stay in `docs/NEXT.md` or a scoped GitHub Issue unless a parked lane
directly unblocks that factory run.

## Reopen Rule

Reopen a parked lane only when it directly answers one factory question:

1. Can we prepare the right data?
2. Can we post-train a better candidate?
3. Can we evaluate it?
4. Can we package it?
5. Can we prove improvement in a report?
