# PostTrainLLM documentation

PostTrainLLM is a **Mac-local learning lab and specialist factory**. The
current owner learning route is the [13-week inference-systems
sprint](learn/inference-systems-13w.md), beginning 28 September 2026. The
retained factory loop is target → data → post-training → eval → package →
report. The docs keep those two jobs separate so an old plan never looks like
today's assignment.

## Start learning

1. [Open the course workspace](learn.md) for the 13-week route and the
   prerequisite path.
2. [Open the single Next Session](learning-progress.md#next-session) for the
   current exercise, evidence to save, and recall schedule.
3. Use the [ground-up curriculum](learn/curriculum.md) only when an entry
   check reveals a gap. The [full learning index](learn/README.md) remains
   available for deeper reading.

The first week asks you to predict tensor shapes and causal influence, trace
token IDs to logits, and run one bounded CPU reference check. No owner
checkpoint or completed mastery gate is implied by this navigation.
